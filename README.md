# Demo-Assignment-


This repository contains three example GitHub Actions workflows.

## Workflows

1. **Hello Workflow**
   - Trigger: Push to `main` branch
   - Action: Prints "Hello GitHub Actions"

2. **Pull Request Workflow**
   - Trigger: Pull request opened or updated against `main`
   - Action: Checks out the repository

3. **Manual Trigger Workflow**
   - Trigger: Manual execution from GitHub Actions UI
   - Action: Prints the current date and time
